## Convenções

| Marcação | Significado |
| --- | --- |
| `E0X-P01` | Pergunta feita pelo entrevistador |
| `E0X-R01` | **Resposta** do participante, com as palavras dele |
| `E0X-O01` | **Observação** do entrevistador; não é fala do participante |
| `E0X-D01` | **Dúvida pendente** para acompanhamento |
| `[inaudível]` | Trecho não compreendido |
| `[colega]`, `[gestor]` | Nome ou detalhe identificador substituído |
| `[não respondeu]` | A pergunta foi feita, mas não houve resposta |
| `[pergunta não feita]` | A pergunta do roteiro não foi feita |

Use os códigos de resposta como fonte na síntese de requisitos, por exemplo: `Origem: E01-R05`.
